AI Trading Agent

Descripción

Proyecto educativo de Inteligencia Artificial y Machine Learning aplicado al análisis del mercado bursátil.

El objetivo es desarrollar progresivamente un agente capaz de analizar datos históricos de acciones, identificar patrones y evaluar posibles movimientos del mercado mediante modelos de aprendizaje automático.

Objetivos del proyecto

* Aprender Python aplicado a ciencia de datos.
* Obtener y procesar datos financieros.
* Analizar tendencias e indicadores técnicos.
* Desarrollar modelos de Machine Learning.
* Comparar y evaluar modelos predictivos.
* Construir un simulador de operaciones bursátiles.
* Crear un dashboard para visualizar resultados.

Tecnologías utilizadas

* Python
* Google Colab
* Pandas
* Matplotlib
* yfinance
* Scikit-learn
* GitHub

Mercado de estudio

Acciones estadounidenses.

Primer activo de estudio: Apple (AAPL).

Este proyecto tiene fines educativos y experimentales. Las operaciones serán simuladas y no representa asesoramiento financiero ni garantiza rendimientos futuros.
